# Prediction-Rotation-Personnel-Salifort
Modélisation prédictive de la rotation du personnel (Churn) utilisant Python et le Machine Learning pour optimiser les stratégies de rétention des employés

# 📈 Prédiction de la Rétention des Employés : Modélisation et Recommandations Stratégiques

## Présentation du Projet
Ce projet analyse les facteurs de rotation du personnel au sein d'une organisation (Salifort Motors). L'objectif principal est de construire un modèle prédictif capable d'identifier les employés susceptibles de quitter l'entreprise, tout en fournissant des recommandations concrètes basées sur les données pour améliorer la culture de travail.

## 📁 Structure du Repository
- **HR_Analytics_Analysis.ipynb** : Analyse complète, de l'exploration des données (EDA) à la modélisation avancée.
- **Salifort_Motors_Strategies.pdf** : Document de planification stratégique utilisant la méthodologie PACE.
- **Executive_Summary_Salifort.pdf** : Résumé décisionnel destiné aux parties prenantes.
- **HR_capstone_dataset.csv** : Données de l'enquête (14 999 lignes, 10 variables).

## 🛠️ Stack Technique
- **Langage :** Python
- **Analyse & Visualisation :** Pandas, NumPy, Matplotlib, Seaborn
- **Machine Learning :** Scikit-Learn (Régression Logistique, Random Forest), XGBoost

## 📊 Résultats Clés
Le modèle final (Random Forest/XGBoost) a démontré une performance exceptionnelle :
- **Exactitude (Accuracy) :** 96,2 % sur l'ensemble de test.
- **Principaux indicateurs de départ :** La surcharge de travail (nombre de projets trop élevé) et l'ancienneté (pic d'insatisfaction à 4 ans).

## 💡 Recommandations Stratégiques
Sur la base de l'importance des variables identifiées par le modèle, voici les axes d'amélioration proposés :
1. **Gestion de la charge de travail :** Plafonner le nombre de projets par employé pour éviter le surmenage.
2. **Reconnaissance de l'effort :** Réformer le système d'évaluation pour ne pas récompenser uniquement les employés dépassant les 200 heures par mois.
3. **Fidélisation ciblée :** Enquêter sur les causes spécifiques d'insatisfaction chez les employés ayant 4 ans d'ancienneté.
4. **Valorisation des heures supplémentaires :** Clarifier les politiques de rémunération et rendre les heures
5. supplémentaires facultatives.
